# Криллион

Русская версия ежедневной игры-погружения [krillion.io](https://krillion.io).

Семь вопросов в день, одинаковые для всех. Считается не правильность ответа,
а его редкость: очевидный вариант почти не тянет вниз, редкий утягивает глубоко.
Каждое очко = 10 метров, 700 очков = 7000 метров, дно впадины.

## Правила

| Тир | Очки | Смысл |
| --- | ---: | --- |
| 🫧 Планктон | 10 | ответ, который выпаливают все |
| 🤡 Слишком умно | 15 | знаменито «редкий» вариант — за него хватаются все |
| 🐟 Косячный | 30 | крепко, плывёшь вместе со стаей |
| 🦑 Редкий | 60 | правда нечастый |
| 🏮 Глубокий рез | 85 | настоящая редкость |
| 🌟 Один на криллион | 100 | заветная жемчужина, дно впадины |

Раунд: 3 секунды на прочтение вопроса, 25 секунд на ответ. Одно погружение
в сутки, день начинается в полночь по Москве.

## Режимы

У каждого свой мир, свой горизонт и свой банк вопросов.

| Режим | Мир | Спуск |
| --- | --- | --- |
| 🦐 **Классика** | океан: корабли, солнце, морской снег | к хадальной зоне |
| ⚽ **Футбол** | ночной стадион: мачты, трибуны, ворота | вниз по футбольной пирамиде — от финала ЛЧ до пустыря за гаражами |
| 🐎 **Казахстан** | степь на закате: юрты, кони, ракета Байконура | сквозь пласты — уголь, медь, кристаллический щит |

Партия, серия и рекорд считаются в каждом режиме отдельно. По дороге вниз
попадаются находки, привязанные к глубине: «Титаник» ровно на 3800 м,
батискаф, чёрный курильщик; трибуна на две тысячи мест и ворота с рваной
сеткой; вагонетка, крепь шахты и жила меди.

Вопросы в каждом режиме намеренно узкие. Банк ответов закрытый, поэтому
спрашивать «назови футбольный клуб» нечестно — верных ответов тысячи, а
принимаются сотни. Вместо этого: «клуб, игравший в АПЛ» (за всю историю их
пятьдесят один), «тренер, выигрывавший Лигу чемпионов», «сборная, игравшая
в финале чемпионата мира».

## Вопросы

В классике темы общечеловеческие — писатели, столицы, реки, сыры, динозавры,
супергерои, музеи, рок-группы. Русский здесь язык, а не предмет: игра не про
Россию. Редкость считается «на слух» русскоязычного игрока — поэтому в
планктоне рядом стоят Шекспир и Пушкин, а в жемчужинах — Гомбрович и Ямусукро.

Банк проверяется скриптом:

```bash
npm run check:data
```

Он ловит дубликаты ответов, конфликты синонимов, пары, которые спутает допуск
на опечатки, и дыры в покрытии тиров. Сейчас: 3 режима, 32 вопроса, 1250 ответов.

## Статистика дня

После погружения видно, как ты выглядишь на фоне остальных: процент нырявших,
которых ты обошёл, место, медиана и рекорд дня, гистограмма по сотням очков с
подсвеченной твоей корзиной. Процент считается по остальным игрокам, а не
включая себя, — иначе «лучше 100%» было бы недостижимо в принципе.

Цифры живут в **Upstash Redis**: гистограмма дня в хеше, повторные отправки
отсекаются ключом игрока с `NX`. Без интеграции модуль падает в память
процесса — игра работает, но блок честно пишет, что общая база не подключена.

Чтобы включить общую статистику:

```bash
vercel link
vercel integration add upstash    # выдаст UPSTASH_REDIS_REST_URL и _TOKEN
vercel env pull .env.local --yes
```

## Аналитика

Подключена [Vercel Analytics](https://vercel.com/docs/analytics) —
`<Analytics />` в корневом лэйауте. Данные собираются только на задеплоенном
проекте.

## Лист ответов

Погружение закончилось — открывается разбор: по каждому раунду видно **все**
принимавшиеся ответы, разложенные по тирам, с ценой каждого тира. Свой ответ
подчёркнут, рядом стоит «сколько взял / сколько было можно».

Лист приходит в ответе `/api/today/complete`, то есть ровно в тот момент, когда
играть уже нечего, и кладётся в `localStorage` — чтобы пережить перезагрузку.
Отдельная ручка `/api/answers` открывает лист только за **прошедшие** дни:
пока день идёт, это был бы готовый ответник.

## Стек

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind v4.
Погружение нарисовано вручную: canvas (небо, солнце, толща воды, морской снег)
плюс DOM-мир, который уезжает вверх по мере набора очков — суда и облака над
водой, отметки глубин и рыбы под ней. Звук — Web Audio, без единого файла.
Оформление пиксельное: срезанные «лесенкой» углы, приборные капсулы, CRT-развёртка,
сонар и фитиль-таймер. Шрифты: Handjet (пиксельный, с кириллицей) и JetBrains Mono.

## Как устроена оценка

У каждого вопроса — закрытый список принимаемых ответов с заранее назначенным
тиром (как и в оригинале: неизвестный ответ отклоняется — «нет отклика»).
Совпадение ищется по нормализованной форме (без регистра, без «ё», без
пунктуации) с допуском на одну-две опечатки; синонимы задаются в поле `a`.

Добавить вопрос — это дописать объект в `lib/prompts.ts`; в выборку дня он
попадёт автоматически.

## Ограничение

Пока не подключён Upstash, `lib/store.ts` считает в памяти процесса: на Vercel
такие счётчики не общие для инстансов и не переживают деплой. Блок статистики
в этом случае прямо пишет об этом, а не выдаёт цифры за общие. Гистограмма
появляется начиная с пяти партий за день.
